Concepto y tipos

Bases de datos Relacionales (RDBMS)

Las bases de datos relacionales son un tipo de base de datos que organiza los datos en tablas relacionadas entre sí mediante claves primarias y foráneas. Cada tabla contiene filas (registros) y columnas (campos), lo que permite una estructura flexible y eficiente para almacenar y recuperar información.

Ejemplos de sistemas de gestión de bases de datos relacionales incluyen MySQL, PostgreSQL

Bases de datos NoSQL

Las bases de datos NoSQL son un tipo de base de datos que no utiliza el modelo relacional tradicional. Estas bases de datos están diseñadas para manejar grandes volúmenes de datos estructurados y semiestructurados, y ofrecen mayor flexibilidad en la organización y el acceso a los datos.

Ejemplos de sistemas de gestión de bases de datos NoSQL incluyen MongoDB, Redis

Estructura de una base de datos relacional

Tablas (Entidades)

Las tablas son la unidad fundamental de almacenamiento en una base de datos relacional. Cada tabla tiene un nombre único y está compuesta por filas (registros) y columnas (campos).

Campos (Atributos)

Los campos son las columnas de una tabla que definen el tipo de datos que se pueden almacenar en cada posición.

Registros (Tuplas)

Los registros son las filas de una tabla que representan una instancia específica de la entidad.

Claves primarias

Las claves primarias son los campos que identifican de manera única cada registro en una tabla.

Relaciones entre tablas

Relación uno a uno (1:1)

En una relación uno a uno, cada registro en la primera tabla está relacionado con un solo registro en la segunda tabla, y viceversa.

Relación uno a muchos (1:N)

En una relación uno a muchos, un registro en la primera tabla puede estar relacionado con múltiples registros en la segunda tabla.

Relación muchos a muchos (N:M)

En una relación muchos a muchos, múltiples registros en la primera tabla pueden estar relacionados con múltiples registros en la segunda tabla. Esto generalmente se implementa mediante una tabla intermedia que contiene claves foráneas de ambas tablas.

Glosario de términos

  • Base de datos: Conjunto organizado de datos que se almacenan y se gestionan de manera eficiente.
  • Tabla: Estructura que organiza los datos en filas y columnas.
  • Campo: Columna de una tabla que define el tipo de datos que se pueden almacenar.
  • Registro: Fila de una tabla que representa una instancia específica de la entidad.
  • Clave primaria: Campo que identifica de manera única cada registro en una tabla.
  • Clave foránea: Campo que establece una relación entre dos tablas.
